# Course Syllabus: Spring Boot Web Development (SAMPLE DATA)

> Sample syllabus made up for testing the AI Chat app. Dates, names and rules are examples.

## General information
- Course code: HSF302 (sample)
- Credits: 3
- Semester: Fall 2026, 10 weeks
- Lecturer: Mr. Nguyen Van An (sample), email an.nv@university.example
- Office hours: Tuesday 14:00–16:00, room 304, building Alpha
- Prerequisites: Object-Oriented Programming with Java, Introduction to Databases

## Learning outcomes
After the course, students can:
1. Build a web application with Spring Boot, Spring MVC and Thymeleaf.
2. Use Spring Data JPA with SQL Server or PostgreSQL, including relationships and pagination.
3. Validate forms with Bean Validation and show errors in the user interface.
4. Build and test REST APIs, and call them from a separate front-end.
5. Deploy an application to a cloud platform.
6. Use AI coding assistants responsibly and explain every line of code they submit.

## Weekly schedule
| Week | Topic |
|------|-------|
| 1 | Spring Boot basics, project structure, Maven |
| 2 | Spring MVC controllers, Thymeleaf templates |
| 3 | Bootstrap with Thymeleaf, layouts and fragments |
| 4 | Spring Data JPA, entities and repositories |
| 5 | Relationships (OneToMany, ManyToOne), pagination, search |
| 6 | Validation and error handling |
| 7 | REST APIs, DTOs, CORS |
| 8 | Spring Security basics, login |
| 9 | Deployment: Docker, Render, Neon, Vercel |
| 10 | Final project presentations |

## Assessment
| Component | Weight |
|-----------|--------|
| Attendance and participation | 10% |
| Lab exercises (8 labs) | 20% |
| Group assignment (slides + user guide) | 20% |
| Final project (group) | 20% |
| Final exam (individual, on computer) | 30% |

- To pass the course, the total score must be at least 5.0 out of 10, AND the final exam score must be at least 4.0.
- Students who miss more than 20% of the sessions are not allowed to take the final exam.
- The final exam lasts 90 minutes. Students may use the official Spring documentation but no AI tools and no internet search.
- One resit exam is allowed. The resit score replaces the final exam score.

## Group work
- Groups have 3 to 5 students.
- The group assignment is due at the end of week 6 (Sunday 23:59).
- The final project is presented in week 10; each presentation is 15 minutes plus 5 minutes of questions.
- Every member must present a part of the project. A member who cannot explain their code may receive a lower individual score.

## Late submission policy
- Late work loses 10% of its score per day, for up to 3 days.
- After 3 days, late work receives 0.
- Extensions are only given for medical or family emergencies, with proof, requested before the deadline.

## Academic integrity
- Using AI assistants (GitHub Copilot, Claude, ChatGPT, Gemini) is ALLOWED for labs, the assignment and the final project, but students must:
  1. state which tools they used and for what, in the user guide;
  2. be able to explain all submitted code.
- Copying another group's work leads to a score of 0 for both groups.
- AI tools are NOT allowed in the final exam.

## Required tools
JDK 21, IntelliJ IDEA (Community or Ultimate), SQL Server 2022 Developer, Git and a GitHub account.
Optional: Docker Desktop, VS Code.
